# AI Asset Generation Prompts

You can copy and paste these prompts into AI image generators (like Midjourney, DALL-E 3, or Adobe Firefly) and AI text generators (like ChatGPT or Gemini) to create the missing assets for your website.

---

## 1. Logo Generation Prompts
*Use these prompts in Midjourney or DALL-E 3.*

**Primary Logo:**
> "A modern, minimalist technology company logo for a brand called 'Technic Technologies'. The logo should feature a sleek 'TN' monogram combined with subtle geometric shapes that represent engineering and innovation. Use a color palette of deep navy blue, vibrant orange, and rose. Vector style, flat design, white background."

**Footer/Monochrome Logo:**
> "A simple, single-color line-art logo for a tech company named 'Technic Technologies'. It should look like a minimalist tech emblem, perhaps featuring a stylized 'T' and 'N' intersecting. Clean lines, monochrome, transparent background."

## 3. Blog Content & Image Prompts
*Use these to generate your pending blog articles and their matching thumbnail images.*

### Blog Post 1: Cloud DevOps
**Image Prompt (Midjourney):**
> "Abstract digital art representing cloud computing and DevOps. Floating servers, glowing network lines connecting data points, deep navy blue and bright orange color scheme, modern tech aesthetic, 16:9 aspect ratio --ar 16:9"

**Content Prompt (ChatGPT/Gemini):**
> "Write a technical 500-word blog post for a company called Technic Technologies about 'The Future of Cloud DevOps automation'. Write in a professional, authoritative tone. Include 3 subheadings and a concluding paragraph."

### Blog Post 2: Cybersecurity
**Image Prompt (Midjourney):**
> "A sleek glowing shield made of digital code and fiber optic light. Representing enterprise cybersecurity and data protection. Deep navy blue background, vibrant orange and rose highlights, highly detailed, 16:9 aspect ratio --ar 16:9"

**Content Prompt (ChatGPT/Gemini):**
> "Write a 500-word blog post for Technic Technologies about 'Zero Trust Architecture in Modern Enterprise Environments'. The tone should be highly technical, reassuring, and professional. Mention our proprietary tool 'TechGuard Sentinel'."

### Blog Post 3: Custom Web Architecture
**Image Prompt (Midjourney):**
> "A futuristic glowing wireframe of a complex website layout floating in space. Digital blueprint concept, neon orange and amber lines over a dark blue background, cinematic lighting, 16:9 aspect ratio --ar 16:9"

**Content Prompt (ChatGPT/Gemini):**
> "Write a 500-word blog post about 'Why Next.js is the Ultimate Framework for High-Performance Marketing Sites'. Focus on server-side rendering, SEO, and fast load times. Write from the perspective of an elite engineering agency."

## 4. Fonts and Typography
When providing instructions to AI agents for frontend UI, use this prompt to ensure the correct fonts are applied:

**UI Agent Prompt:**
> "When building components, ensure that headings utilize the **Raleway** font for an elegant touch, while main body text uses **Inter**. Use **Roboto** for any technical data, code snippets, or small metadata. Ensure all styling matches our dark navy and orange/rose gradient theme."
